# Uptrace Logo & Web Assets Directory

You can drop your real SVG asset files into this folder:

### Supported Logo File Names:
- `render.svg` — Render Cloud
- `supabase.svg` — Supabase PostgreSQL
- `vercel.svg` — Vercel Edge
- `neon.svg` — Neon Serverless Postgres
- `railway.svg` — Railway
- `postgres.svg` — PostgreSQL Database
- `redis.svg` — Redis Cache
- `aws.svg` — Amazon Web Services
- `github.svg` — GitHub Actions & Auth

Any SVGs placed here will immediately be served across the dashboard and trust bar!
